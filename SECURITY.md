# Security

PermaEnv is pre-alpha. Only the latest development revision receives fixes at this stage.
The current diagnostic command does not run discovered applications or read their settings.

Please report suspected vulnerabilities using
[GitHub private vulnerability reporting](https://github.com/ogbozoyan/PermaEnv/security/advisories/new).
Include a minimal reproduction using synthetic data, the affected revision, OS and Python version.
Do not include secrets or private backups, and do not open a public issue containing exploit details.

If the private reporting form is unavailable, open an issue requesting a private contact
channel **without vulnerability details** so the maintainer can arrange one.
